# Introduction

This directory holds the public-baseline implementation code, protocol and results.
`public_baseline_code_logs_results` is a filtered snapshot that keeps the training / evaluation /
monitoring code, the external-baseline code, all baseline logs, the summary / progress / report
files, and the SelaFD pretrained `.pth`, but excludes the public-baseline trained checkpoint
`.pt` files. `protocol_and_results` holds the public-baseline protocol and the final
strong-baseline unified evaluation table, in which row 9 is `DINOv3 ViT-L/16` and row 10 is
`proposed`.
